Documentación del proyecto Bizagi2

Wiki Backend: aplicación web con Spring Boot para presentar al equipo de trabajo.

Descripción

La wiki muestra la información de los integrantes del equipo y permite enviar mensajes mediante un formulario de contacto. Los datos se guardan en PostgreSQL y las vistas se generan dinámicamente con Thymeleaf.

Tecnologías

ComponenteUso
Java 21 / Spring Boot 4Backend y servidor web
Spring Data JPA / HibernatePersistencia
ThymeleafMotor de plantillas HTML
Bean ValidationValidación del formulario de contacto
PostgreSQLBase de datos wiki
Maven, Docker, Docker ComposeConstrucción y despliegue

Modelo de datos

Formulario de contacto

Se accede desde /grupo con el botón Contáctanos. Si los datos son inválidos, se vuelve a mostrar el formulario con los errores; si son correctos, se guarda el mensaje y se muestra una confirmación. Consulta de los mensajes guardados:

SELECT id, nombre, email, asunto, mensaje, created_at
FROM contactos
ORDER BY created_at DESC;

Ejecución

Con Docker

docker compose up --build

Sin Docker

Requiere PostgreSQL local con la base wiki. La conexión se configura con las variables DB_URL, DB_USER y DB_PASSWORD (por defecto jdbc:postgresql://localhost:5432/wiki, postgres y javeriana).

.\mvnw.cmd spring-boot:run

La aplicación queda en http://localhost:8080.
